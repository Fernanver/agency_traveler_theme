# Traveler Agency — Tema de WordPress

Tema personalizado de WordPress para una agencia de viajes, hecho como proyecto de práctica para aprender PHP, reforzar JavaScript y entender cómo funciona un tema por dentro: del maquetado a la lógica que lo hace funcionar.

🔗 **Demo en vivo:** [traveler-agency-est.infinityfreeapp.com](https://traveler-agency-est.infinityfreeapp.com)

![Screenshot del sitio](ruta-o-link-de-la-imagen)

## ✨ Características

- Diseño propio, sin plantillas prediseñadas
- Entradas de destinos (Tokyo, Finlandia, Perú)
- Estilos personalizados en CSS
- JavaScript para la interactividad
- Compatible con WordPress 7.x

## 🛠️ Tecnologías

- WordPress
- PHP
- MySQL
- HTML / CSS / JavaScript

## 📦 Instalación

1. Descarga o clona este repo dentro de `wp-content/themes/`:
```bash
   cd wp-content/themes
   git clone https://github.com/TU-USUARIO/NOMBRE-DEL-REPO.git traveler-agency
```
2. En el panel de WordPress ve a **Apariencia → Temas**
3. Activa **Traveler Agency**
